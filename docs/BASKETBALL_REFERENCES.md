# Basketball referee and ball references

The local illustrated supplement **Basketball-Referenzen/index.html** contains the
three user-supplied charts dated 4 November 2026: one referee-uniform overview and
two basketball overviews. Prepared hall folders receive a documentation-only copy.
The charts remain outside Git because redistribution rights have not been established.
They are visual references, not a verified official season/league equipment database.

## Referee clothing

The illustrations cover grey shirts with black sleeves, orange/black shirts,
dark shirts with neon trim, and vertical black/white stripes, with long black
trousers and black sports shoes. The existing basketball library plans twelve
referee cutouts across these four style families. All have label `referee`; kit,
requested gender and requested skin tone do not create extra detector classes.
Futsal shirts, shorts and knee socks are documented separately in [FUTSAL_HALL.md](FUTSAL_HALL.md).

## Basketball appearances

The first new chart contains twelve illustrated examples; the second contains ten.
Together they show orange, dark-brown, orange/cream and orange/black surfaces with
varied panel patterns. All remain label `ball`, regardless of displayed brand or
competition. The existing batch extracts ten ball faces from its configured local
reference sheet; rotations, apparent sizes, placements and occlusions vary between
scenes. Adding these documentation images does not change that sheet, ball crops,
completed datasets, run configuration or frozen engine.

The charts include size-6/size-7 examples. Treat the displayed manufacturers,
league assignments and season claims as unverified illustration captions. The
current compositor varies approximate ball size; it does not simulate a branded
physical ball. Clothing, anatomy and visual integration still need contact-sheet
review. Canonical basketball labels stay `ball`, `player`, `referee`, `hoop`.

See [training diversity proposals](DATA_AUGMENTATION.md) for economical variations
and label/split safeguards. The local supplement embeds the charts and a German
explanation; no user image is relicensed under the code's Apache-2.0 license.
