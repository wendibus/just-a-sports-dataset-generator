# Dependencies and asset provenance

The application runs locally without fees, subscriptions, hosted inference, or model downloads. Installation obtains ordinary open-source Python packages; dataset processing does not contact a service.

The export milestone was checked with these distributions on macOS, Python 3.12. License identifiers below come from the installed package metadata. Keep the relevant license notices when distributing packages; Apache-2.0 for this repository does not replace third-party terms.

Pillow is the only direct Python runtime dependency. The 3D basketball backend additionally requires a locally installed Blender 5.x executable; it is not downloaded or bundled. COCO validation tools and their NumPy dependency are development dependencies, not required for generation/export. No third-party imagery, athletes, model weights, motion captures, textures, or geometry assets are bundled. The reference fixture is generated entirely by repository code under Apache-2.0. The new basketball geometry and materials are generated by the isolated Blender worker under GPL-3.0-or-later; its source hash and Blender version are recorded in scene/run provenance. The host remains Apache-2.0 and communicates via subprocess/JSON/image files. The GPL notice is included with the worker and in the Mac package. Blender's [licensing explanation](https://www.blender.org/about/license/) distinguishes its software license from generated artwork.

RF-DETR is the target training framework in Reco Trainer. Dataset generation itself needs no detection model or weights. This repository neither installs a YOLO/Ultralytics dependency nor exports YOLO data. Full RF-DETR training is performed by Reco Trainer, outside the generator's format/import tests.

Reco Trainer is fetched only for the explicit CI compatibility test (or supplied as a local checkout). It is not bundled, modified, imported by the application, or used as a hosted service. The tests execute its existing local COCO importer and RF-DETR dataset builder against temporary synthetic data.

The Mac bundle inventories Python, Pillow and bundled image libraries, OpenSSL, mpdecimal, and the Blender worker, retaining their notices under Lizenzen. Future photorealistic asset packs require separate source, license, redistribution, and no-cost checks before adoption. No downloaded asset pack is approved by this milestone.
